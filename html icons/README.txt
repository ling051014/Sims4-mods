L1nG Genealogy local SVG icons

Sources:
- Bootstrap Icons (MIT)
- Material Design Icons / @mdi/svg (Apache-2.0)

Icons are stored as standalone SVG files under this directory.
The UI renders them through CSS mask-image + currentColor, so icon colors follow the active theme automatically without editing the SVG files.
