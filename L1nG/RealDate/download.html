L1nG_RealDate.package L1nG_RealDate.ts4script

相容檔只處理對應模組的介面、顯示內容與部分功能； 不影響 RealDate 核心日期與年齡計算。

Compatibility packages handle UI/display and certain integration behavior; they are not required for RealDate's core date and age calculations.

COMPATIBILITY FILES

相容檔怎麼選？

Which compatibility package should I use?

你的模組組合 Your setup 安裝這個相容檔 Install this package
只有 UI Cheats UI Cheats only L1nG_RealDate_Compat_UI_Cheats.package
只有 Quick Save Button Quick Save Button only L1nG_RealDate_Compat_QuickSave.package
UI Cheats + Quick Save Button L1nG_RealDate_Compat_QuickSave_UI_Cheats.package
上面三個相容檔只能擇一安裝，否則會互相衝突。 Only one of the three packages above may be installed; using more than one causes conflicts.

BetterBuildBuy

L1nG_RealDate_Compat_BetterBuildBuy.package

保留滑鼠懸停市民時，頭頂名稱介面的 RealDate 實際年齡顯示。

Preserves RealDate real-age display in Sim nameplates.

Slice of Life Menstrual Cycle

L1nG_RealDate_Compat_SliceOfLife_Menstrual.package

讓月經特徵卡說明同步顯示 RealDate 週期資訊；未安裝不影響週期玩法本身。

Shows RealDate cycle information in the menstrual trait card; cycle gameplay still works without it.

Mood Pack Mod

L1nG_RealDate_Compat_MoodPack.package

讓生日與紀念日社交有更豐富的情緒反應；未安裝時使用 EA 原生情緒。

Adds more varied emotional reactions to birthday and anniversary socials; EA native moodlets are used without it.
