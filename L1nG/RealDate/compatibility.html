Compatibility

RealDate 的整合原則是： RealDate 負責「什麼時候」，原模組負責「發生什麼」。 這一頁把測試版本、整合範圍、是否需要相容檔，以及原模組仍負責的內容分開寫清楚。

RealDate follows one rule: RealDate handles “when,” while the original mod handles “what happens.” Tested versions, integration scope, compatibility packages, and responsibility boundaries are documented separately below.

DETAILS

完整相容說明

Detailed Compatibility

UI Cheats Extension v1.59.1 已支援 · 需要相容檔 Supported · package required

使用 UI Cheats 操作季節 / 時間相關介面時，RealDate 會維持自己的日期與時間一致性。 RealDate 的 UI 相容檔則負責避免雙方修改同一介面資源時互相覆蓋。

RealDate keeps its date/time state consistent when UI Cheats is used on supported time-related UI. The compatibility package prevents both mods from overwriting the same UI resources.

v0.4 測試版本 Tested with v0.4 UI Cheats v1.59.1
只有 UI Cheats UI Cheats only L1nG_RealDate_Compat_UI_Cheats.package
UI Cheats + Quick Save UI Cheats + Quick Save L1nG_RealDate_Compat_QuickSave_UI_Cheats.package
UI Cheats、Quick Save、Quick Save + UI Cheats 三個版本只能擇一安裝。 Choose only one of UI Cheats, Quick Save, or Quick Save + UI Cheats compatibility packages.
MC Command Center (MCCC) 2026.5.0 已支援 Supported

RealDate 會處理

Handled by RealDate

  • MCCC 市民資訊顯示 RealDate 實際年齡。
  • Show RealDate age in MCCC Sim Info.
  • 協調停止增齡、自訂生命階段長度與隨機起始進度等生命週期設定。
  • Coordinate lifecycle settings such as disabled aging, custom stage lengths, and randomized starting progress.
  • 辨識由 MCCC 作弊開始的懷孕，並在取得可靠進度時建立 / 推算 RealDate 懷孕時間軸。
  • Recognize pregnancies started with MCCC cheats and build / estimate the RealDate pregnancy timeline from reliable progress.

RealDate 不會做

Not handled by RealDate

  • 不會自行改寫玩家的 MCCC 設定。
  • Does not silently rewrite MCCC settings.
  • 懷孕結束不會在沒有可靠生產證據時直接當作已生產。
  • Does not treat every pregnancy ending as a birth without reliable birth evidence.
v0.4 測試版本 Tested with v0.4 MCCC 2026.5.0
WickedWhims v185k 已支援 Supported

RealDate 讀取可用的月經週期與懷孕進度，並把支援的時間資料同步進 RealDate 生理時間軸。 WickedWhims 原本的情緒、症狀、用品、通知與互動仍由 WickedWhims 自己負責。

RealDate reads supported menstrual-cycle and pregnancy progress and synchronizes timing into its reproductive timeline. WickedWhims continues to control its own moods, symptoms, products, notifications, and interactions.

v0.4 測試版本 Tested with v0.4 WickedWhims v185k
Slice of Life Menstrual Cycle Slice of Life v1.2 / Strawberry 0.7 已支援 · 選擇性顯示相容檔 Supported · optional display package

RealDate 會同步 SOL 原本的經期與週期狀態；修改生日或年齡後，也會重新同步週期與停經狀態。 額外相容檔只負責特徵卡說明顯示，不安裝也不影響核心週期同步。

RealDate synchronizes SOL's native period/cycle states and resynchronizes cycle and menopause states after birthday or age changes. The extra package only handles trait-card display and is not required for core timing synchronization.

v0.4 測試版本 Tested with v0.4 Slice of Life v1.2 / Menstrual Cycle Strawberry 0.7

Relationship & Pregnancy Overhaul (RPO) v2.986 已支援 · 懷孕流程 Supported · pregnancy flow

RealDate 會辨識 RPO 參與的懷孕開始、結束與生產結果，維持 RealDate 自己的受孕日期、孕期與產後時間線。

RealDate recognizes RPO pregnancy starts, endings, and birth outcomes while maintaining its own conception, pregnancy, and postpartum timeline.

RealDate 日期、孕期時間、必要的同步判斷 Dates, pregnancy timing, required synchronization
RPO 關係、反應、結果與其他 RPO 玩法 Relationships, reactions, outcomes, and other RPO gameplay
