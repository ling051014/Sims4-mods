FAQ

常見問題

Frequently Asked Questions

RealDate 一定需要《春夏秋冬》嗎？Does RealDate require Seasons?

不需要。核心日期、出生年份、實際年齡與年齡特徵不依賴《春夏秋冬》。

No. Core date, birth-year, real-age, and age-trait features do not depend on Seasons.

必要前置是什麼？What dependency is required?

v0.4 測試環境使用 Lot51 Core Library v1.43；下載與安裝頁有原作者連結。

The v0.4 tested environment uses Lot51 Core Library v1.43; the Download & Install page links to the original creator.

RealDate 支援哪些遊戲語言？Which game languages are supported?

所有《模擬市民 4》遊戲語言都能載入；完整翻譯目前提供繁體中文、簡體中文與英文，未完整翻譯的文字會回退英文。

RealDate can load in all Sims 4 game languages. Full translations are currently provided in Traditional Chinese, Simplified Chinese, and English; untranslated text falls back to English.

新生兒滿 1 個月算生日嗎？Is one month old a birthday?

不是。滿月會沿用 EA 增齡流程進入嬰兒，但不觸發 RealDate 年度生日通知。

No. The Sim uses EA's age-up flow to become an Infant, but it does not trigger the yearly RealDate birthday notification.

到預產期會被 RealDate 強迫生產嗎？Does RealDate force birth at the due date?

不會。真正的懷孕與生產玩法仍由 EA 或其他模組負責。

No. Pregnancy and birth gameplay remain controlled by EA or other mods.

相容檔要放哪裡？Where do compatibility packages go?

Mods\Overrides

UI Cheats 和 Quick Save 的相容檔可以一起裝嗎？Can UI Cheats and Quick Save compatibility packages be installed together?

不能。UI Cheats、Quick Save、Quick Save + UI Cheats 三個相容檔只能擇一。

No. Choose only one of UI Cheats, Quick Save, or Quick Save + UI Cheats compatibility packages.

歷史版本可以直接下載嗎？Can I directly download historical releases?

可以。網站已內建 v0.1～v0.4 的實際發布 ZIP；一般玩家仍建議優先使用最新公開版本。

Yes. The site includes the actual v0.1–v0.4 release archives; most players should still use the latest public release.
