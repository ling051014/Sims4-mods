常見問題

Frequently Asked Questions

是否必須安裝《春夏秋冬》？Is Seasons required?

不需要。RealDate 的日期、出生年份、實際年齡和年齡特徵等核心功能不依賴《春夏秋冬》。與 EA 季節系統相關的功能則以完整玩法說明為準。

No. Core dates, birth years, ages and age traits do not require Seasons. See Gameplay for features involving EA's seasonal system.

安裝 RealDate 需要哪些檔案？Which files do I need to install?

請先安裝必要前置 Lot51 Core Library；v0.5 Beta 的發布測試環境使用 v1.43。再安裝 RealDate 的 .package 與 .ts4script 主檔，並依自己的模組組合選用相容檔。完整步驟請參閱下載與安裝。

Install the required Lot51 Core Library first (v1.43 in the v0.5 Beta tested environment), then both RealDate .package and .ts4script files. Add matching compatibility packages as needed. See Installation.

目前支援哪些遊戲語言？Which game languages are supported?

模組可在各種《模擬市民 4》遊戲語言下執行。目前提供繁體中文、簡體中文與英文完整翻譯，其他語言未翻譯的內容會以英文顯示。

The mod can run with all Sims 4 game languages. Complete translations are available in Traditional Chinese, Simplified Chinese and English. Untranslated text in other languages falls back to English.

更新模組前需要做什麼？What should I do before updating?

建議先備份存檔，並移除舊版 RealDate 的 .package 與 .ts4script，再安裝新版。請一併檢查相容檔是否需要更換，避免不同版本混用。各版本的變更請參閱更新日誌。

Back up your saves, remove the previous RealDate .package and .ts4script, then install the new release. Update any compatibility packages as needed and avoid mixing versions. See the Changelog.

如何設定 Overrides 與 Resource.cfg？How do I set up Overrides and Resource.cfg?

RealDate 的相容檔需要放進 Mods\Overrides。Resource.cfg 是告訴遊戲「到哪裡找模組、哪個資料夾優先」的設定檔。

RealDate compatibility packages go in Mods\Overrides. Resource.cfg tells the game where to find mods and which loading rules take priority.

01

找到 Resource.cfg

Find Resource.cfg

開啟 文件 / Electronic Arts / The Sims 4 / Mods，找到 Resource.cfg，再用 Windows「記事本」開啟。

Open Documents / Electronic Arts / The Sims 4 / Mods, find Resource.cfg, and open it with Notepad.

02

看看 Overrides 是否已經設定好

Check whether Overrides is already configured

在記事本按 Ctrl + F，搜尋 Overrides。你可能會看到類似這樣的內容：

Press Ctrl + F in Notepad and search for Overrides. Your file may contain something like this:

Resource.cfg 範例節錄（不是完整檔案）Resource.cfg excerpt (not a complete file)
Priority 500
PackedFile *.package
PackedFile */*.package

Priority 600
PackedFile Overrides\*.package

500 是一般模組、600 是 Overrides。因為 600 比 500 大，所以 Overrides 的讀取優先級較高。

500 is for regular mods and 600 is for Overrides. Since 600 is higher, Overrides has a higher loading priority.

PackedFile Overrides\*.package 則是讀取 Overrides 資料夾內的 .package 檔案。

PackedFile Overrides\*.package loads .package files directly inside Overrides.

03

找不到 Overrides 設定時，才需要新增

Only add a rule if none exists

先複製一份原本的 Resource.cfg 作為備份。如果一般模組使用 Priority 500，可以在原有內容的最後新增以下兩行：

Make a backup of your current Resource.cfg. If your regular mods use Priority 500, add these two lines at the end of the existing file:

只有需要新增設定時才複製Copy only when adding a rule 
Priority 600
PackedFile Overrides\*.package

按 Ctrl + S 儲存。保留原本的其他內容，並確認檔名仍是 Resource.cfg，不是 Resource.cfg.txt。

Press Ctrl + S to save. Keep all other lines intact and make sure the filename is Resource.cfg, not Resource.cfg.txt.

上述 500 / 600 只是範例，你的 Resource.cfg 可能有更多行或使用不同的 Priority。只要 Overrides 已有對應讀取規則，且優先級高於一般模組，就不必修改；如果需要新增，請依現有設定調整數字，不要直接照貼。

The 500 / 600 values are examples. Your Resource.cfg may contain more rules or different priority numbers. If Overrides already has a matching rule with higher priority than regular mods, no changes are needed. Otherwise, adjust the values to your existing setup rather than copying them blindly.

04

放入 RealDate 相容檔

Place your RealDate compatibility packages

在 Mods 裡找到或建立 Overrides 資料夾，把需要的 RealDate 相容檔直接放進去。

Find or create the Overrides folder inside Mods, then place the RealDate compatibility packages you need directly inside it.

資料夾放置範例Example folder structure
Mods
├─ Resource.cfg
└─ Overrides
   └─ L1nG_RealDate_Compat_UI_Cheats.package

只以 UI Cheats 相容檔為例。未安裝對應第三方模組時，不需要放入那個相容檔；完成後重新啟動遊戲。

UI Cheats is only an example. Do not install compatibility packages for third-party mods you don't use. Restart the game afterward.

UI Cheats 與 Quick Save 的相容檔可以同時安裝嗎？Can UI Cheats and Quick Save packages be installed together?

不能將三個互斥的版本一起安裝。請依安裝組合，從「只有 UI Cheats」、「只有 Quick Save」及「UI Cheats + Quick Save」三種相容檔中擇一；詳細檔名見相容檔選擇。

Do not install all three mutually exclusive variants. Choose exactly one: UI Cheats only, Quick Save only, or the combined UI Cheats + Quick Save package. See Compatibility package selection.

RealDate 會在預產期強制生產嗎？Does RealDate force childbirth on the due date?

不會。RealDate 記錄與同步懷孕相關日期，但真正的生產流程仍由 EA 原版遊戲或已安裝的其他模組控制；到達預產期不代表會立即強制生產。

No. RealDate tracks pregnancy dates, but childbirth remains controlled by EA or compatible third-party mods. Reaching the due date does not trigger forced delivery.

新生兒滿月算是年度生日嗎？Is a newborn's first month an annual birthday?

不是。新生兒滿月會沿用 EA 的增齡流程進入嬰兒階段，但不會因此觸發 RealDate 的年度生日通知。

No. A newborn reaching one month uses EA's age-up flow to become an Infant, but does not trigger RealDate's annual birthday notification.

可以下載歷史版本嗎？Are previous versions available?

可以。歷史版本頁段提供已發布的版本檔案，主要供存檔環境維持、對照或測試使用。一般情況建議使用與目前遊戲版本相容的最新公開版。

Yes. The release archive contains previous public versions for reference and testing. For regular use, choose the latest public version compatible with your game.
