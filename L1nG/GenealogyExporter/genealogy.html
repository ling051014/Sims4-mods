      畫布與佈局

      • 自動排列時，拖曳空白處平移整個族譜畫布；滾輪以滑鼠游標所在位置為中心縮放畫布
      • 雙擊空白處讓族譜置中並配合視窗大小顯示
      • 拖曳卡片拖曳超過判定距離後，會切換為「自由排列」並保留調整後的位置
      • 自由排列會出現選取與拖曳工具：選取工具下拖曳空白處可框選模擬市民；拖曳工具下拖曳畫布可平移視角
      • 選取工具支援 Shift + 左鍵增減多選、Ctrl / Cmd + A全選目前畫布模擬市民；拖曳任一已選模擬市民可整組移動
      • 使用選取工具時可按住 Space + 左鍵暫時拖動畫布，放開後回到選取工具
      • 市民卡片使用 左鍵檢視模式查看資料 / 編輯模式編輯模擬市民；右鍵開啟卡片設定與模擬市民快捷操作
      • 智慧對齊輔助線會在卡片接近其他卡片的左側、中心、右側或頂端、中心、底端時自動吸附對齊
      • 等距吸附適用於水平與垂直排列；接近等距位置時會顯示間距提示，只調整正在拖曳的卡片
      • 自由排列時可使用鎖定排列避免誤拖；重設位置會清除目前模式中手動調整的位置，並重新自動排列
      • 側邊欄分隔線可拖曳調整寬度；雙擊分隔線即可還原預設寬度

      畫布與觸控操作

      • 一般操作或拖曳工具下，單指拖曳空白處可平移整個族譜畫布。
      • 快速點兩下空白畫布可自動適應畫面並置中族譜。
      • 雙指靠近／拉開可縮放畫布；雙指一起移動時也會同步平移視角。
      • 點一下市民卡片可查看模擬市民資料或進入編輯；長按市民卡片可開啟卡片設定與模擬市民快捷操作。
      • 拖曳市民卡片可移動模擬市民；在自動排列下拖曳超過判定距離後，會切換為自由排列並保留新位置。
      • 選取工具下，點模擬市民可加入或取消選取；拖曳任一已選模擬市民可整組移動。
      • 選取工具下，拖曳空白處可框選模擬市民；點一下空白處可取消目前選取。
      • 拖曳市民卡片接近其他卡片時，仍會使用智慧對齊與等距吸附。
      • 自由排列時可使用鎖定排列避免誤拖；重設位置會清除目前模式中手動調整的位置，並重新自動排列。

      關係與關係位置

      • 顯示 / 隱藏關係控制畫布上的關係名稱是否顯示
      • 關係未鎖定時可直接拖曳關係名稱；接近原本的水平或垂直位置時，會自動吸附回去
      • 鎖定關係可避免誤拖關係名稱
      • 要還原關係名稱的位置，可前往編輯模擬市民的關係清單，點選重設回到自動位置

      匯出與備份

      • 點選頂端匯出可選擇族譜圖片或JSON 備份
      • 族譜圖片會匯出整張族譜，不受目前畫布的縮放或平移位置影響
      • 圖片會保留目前的卡片位置、關係名稱位置、主題與背景，但不包含網站導覽、側邊欄、對齊輔助線或拖曳狀態
      • 族譜圖片可選擇標準（1×） / 高畫質（2×） / 超高畫質（3×）
      • JSON 備份會保存族譜資料與圖片，日後匯入備份即可繼續編輯

      人生照片

      • 編輯模擬市民 →人生照片：替模擬市民保存值得記錄的照片
      • 每張圖片可設定：標題 / 關聯階段 / 備註
      • 支援拖曳圖片檔案到人生照片區，或按Ctrl + V貼上截圖
      • 手機或觸控裝置可按「新增圖片」後使用「選擇圖片」，從裝置中挑選照片。

      圖片儲存

      • 頭像、人生照片、寵物圖片與背景圖片會儲存在目前使用的瀏覽器中，不會自動上傳到網站或伺服器
      • 匯出 JSON 備份時，圖片會自動一起放進備份；之後重新匯入時也會一併還原
      • 清理未使用的圖片只會移除目前沒有被模擬市民、寵物、人生照片或背景使用的圖片，不會刪除仍在使用中的圖片

      快捷鍵

      • Ctrl + Z復原上一個卡片或關係名稱拖曳；輸入欄位內仍使用瀏覽器原生文字復原
      • Ctrl + Y或Ctrl + Shift + Z重做上一個拖曳操作
      • Esc關閉目前彈出視窗
      • ←→圖片檢視器中切換上一張 / 下一張
      • Ctrl + V圖片編輯視窗內貼上剪貼簿圖片
      • Ctrl + S在編輯彈出視窗中快速儲存
