EXPORTER

把遊戲裡已經存在的家族故事，帶進你的族譜。

Bring the family history already living in your save into your genealogy.

族譜資料提取模組以唯讀方式讀取目前存檔中的模擬市民、家庭與族譜關係， 整理成一份可直接匯入 L1nG 網頁端族譜系統工具的 ZIP。

Genealogy Exporter reads Sims, households, and family-tree relationships from the current save in read-only mode, then packages them into a ZIP that can be imported directly into L1nG Genealogy.

可提取內容WHAT IT EXPORTS

不是重做一份族譜，是把存檔裡已經存在的資料帶出來。

It does not rebuild your family tree. It carries out what already exists in the save.

Exporter 會先讀取 EA 的 FamilyTree、SimInfo 與 Household，再把可用欄位整理成網頁端可理解的格式。

The exporter reads EA FamilyTree, SimInfo, and Household data, then normalizes available fields for the web tool.

使用流程WORKFLOW

從遊戲到族譜，四個步驟。

From the game to your family tree in four steps.

01

安裝族譜資料提取模組

Install Genealogy Exporter

將模組放入 Mods，並確認遊戲已開啟「自訂內容與模組」以及「允許腳本模組」。

Place the mod in Mods and make sure Custom Content & Mods and Script Mods are enabled.

02

進入要匯出的存檔

Load the save you want to export

等待遊戲完成載入。資料提取模組需要目前存檔的 FamilyTreeService 已經準備完成。

Wait for the save to finish loading so FamilyTreeService is available.

l1ng.genealogy.status
03

執行唯讀匯出

Run the read-only export

開啟作弊指令列並執行匯出指令。完成後遊戲會顯示人物、家庭、關係邊、錯誤數與輸出路徑。

Run the export command. The game reports Sim, household, relationship-edge, error counts, and the output path.

l1ng.genealogy.export
04

把 ZIP 匯入族譜工具

Import the ZIP into Genealogy

打開網頁端族譜系統工具，在「更多 → 匯入遊戲族譜」選擇剛剛輸出的 ZIP。

Open the Genealogy web tool, then choose More → Import Game Genealogy and select the exported ZIP.

開啟族譜工具 → Open Genealogy →
預設輸出位置 Default export location Documents\Electronic Arts\The Sims 4\L1nG_Genealogy_Exports

每次匯出會建立帶有日期時間的 L1nG_Genealogy_Export_*.zip。

Each export creates a timestamped L1nG_Genealogy_Export_*.zip.

匯出檔案EXPORT BUNDLE

一份 ZIP，就是一次存檔快照。

One ZIP is one snapshot of your save.

資料提取模組不會建立線上帳號，也不會同步到伺服器。網頁工具讀取你手動選擇的 ZIP， 再把人物與族譜資料轉成族譜工具自己的資料格式。

The exporter creates no online account and performs no server sync. The web tool reads the ZIP you explicitly choose and converts its contents into Genealogy's own data model.
