使用方式HOW TO USE

四個步驟，完成族譜匯出

Export your genealogy in four steps

01

安裝族譜提取器

Install Genealogy Exporter

解壓縮後，將 .ts4script 與 .pyd 放進 Mods 內同一個資料夾，並在遊戲設定中開啟「自訂內容與模組」及「允許腳本模組」

After extracting the download, place the .ts4script and .pyd files in the same Mods subfolder, then enable Custom Content & Mods and Script Mods in game settings

v0.1 Beta Windows x64
02

載入要匯出的存檔

Load your save

進入生活模式並等待存檔載入完成，如需確認提取器是否啟動，可按 Ctrl + Shift + C 開啟遊戲指令輸入框，再點擊右側指令複製、貼上並執行

Enter Live Mode and wait for your save to finish loading. To check that the exporter is running, press Ctrl + Shift + C to open the cheat console, then click the command on the right to copy, paste, and run it

03

執行族譜匯出

Export your genealogy

按 Ctrl + Shift + C 開啟遊戲指令輸入框，點擊右側指令複製並貼上執行，等待匯出完成後即可取得 ZIP 檔案

Press Ctrl + Shift + C to open the cheat console, then click to copy the command on the right, paste it into the game, and wait for the ZIP export to finish

04

匯入網頁族譜

Import into Genealogy

將 ZIP 拖曳到族譜工具的畫布，或透過「更多 → 匯入遊戲族譜」選取檔案；匯入後的操作可參考族譜工具內的「使用說明」

Drag the ZIP onto the Genealogy canvas, or select it from More → Import Game Genealogy. For editing and other features, see Help in the Genealogy tool

開啟族譜工具 → Open Genealogy →
預設輸出位置 Default export folder Documents\Electronic Arts\The Sims 4\L1nG_Genealogy_Exports

每次匯出都會建立附有日期與時間的 L1nG_Genealogy_*.zip，匯入網站時選取這份檔案即可

Each export creates a dated L1nG_Genealogy_*.zip. Choose this file when importing into the website

匯出檔案YOUR EXPORT FILE

將族譜資料整理成 ZIP

Your genealogy data in one ZIP

這份 ZIP 包含提取的人物、家庭、族譜資料與頭像，檔案會留在你的電腦中，直到你自行選取匯入；它不是遊戲存檔備份

The ZIP contains exported Sims, households, family relationships, and available portraits. It stays on your computer until you choose to import it; it is not a backup of your game save
