使用提示— 快速上手與快捷鍵

畫布與佈局

  • 自動佈局時，拖曳空白處平移整個族譜畫布；滾輪以滑鼠位置為中心縮放
  • 雙擊空白處自動適應螢幕
  • 拖曳卡片超過拖曳門檻後會自動切換為「自由排列」，並儲存新位置
  • 自由排列會出現選取與拖曳工具：選取工具下拖曳空白處可框選人物；拖曳工具下拖曳畫布可平移視角
  • 選取工具支援 Shift + 左鍵增減多選、Ctrl / Cmd + A全選目前畫布人物；拖曳任一已選人物可整組移動
  • 使用選取工具時可按住 Space + 左鍵暫時拖動畫布，放開後回到選取工具
  • 人物卡使用 左鍵檢視模式查看資料 / 編輯模式編輯人物；右鍵開啟卡片設定與人物快捷操作
  • 智慧對齊輔助線會在單張卡片接近其他卡片的左 / 中 / 右或上 / 中 / 下位置時自動吸附
  • 等距吸附支援水平與垂直排列；接近相同間距時會顯示兩段間距與數值，只移動目前拖曳的卡片
  • 自由排列時可使用鎖定排列避免誤拖；重設位置會清除目前模式的手動位置並恢復自動樹狀佈局
  • 側邊欄分隔線可拖曳調整寬度；雙擊分隔線恢復預設寬度

關係與關係位置

  • 顯示 / 隱藏關係控制畫布上的關係名稱是否顯示
  • 關係未鎖定時可直接拖曳關係名稱；接近原始水平或垂直位置時會分別吸附回原位
  • 鎖定關係可避免誤拖關係名稱
  • 已移動的關係名稱可在模擬市民編輯視窗的關係清單中按重設回到自動位置

匯出與備份

  • 點選頂端匯出可選擇族譜圖片或JSON 備份
  • 族譜圖片會輸出目前完整族譜，不受目前縮放或平移視角限制
  • 圖片會保留目前的卡片位置 / 關係位置 / 主題 / 背景，但不包含頂端導覽、側邊欄、智慧輔助線或拖曳狀態
  • 族譜圖片可選擇標準（1×） / 高畫質（2×） / 超高畫質（3×）
  • JSON 備份保留可再次匯入的完整族譜資料，瀏覽器中的圖片會一併轉回 base64

相簿瀏覽器

  • 頂端相簿：開啟相簿瀏覽器，檢視所有模擬市民的相簿圖片
  • 頂端支援按標題 / 模擬市民名稱 / 備註搜尋，按模擬市民篩選
  • 每張卡片顯示來源模擬市民與標題；點選開啟大圖檢視器
  • 檢視器中←→跨模擬市民瀏覽，Esc關閉
  • 不包含頭像 / 寵物頭像 / 背景圖

模擬市民相簿

  • 編輯模擬市民 →相簿：為模擬市民新增多張圖片
  • 每張圖片可設定：標題 / 關聯階段 / 備註
  • 支援拖曳圖片檔案到相簿網格，或按Ctrl+V貼上截圖

圖片儲存

  • 圖片儲存在瀏覽器IndexedDB中，容量通常遠大於 localStorage
  • 首次開啟會自動把舊資料（base64）遷移到 IndexedDB
  • 可在主題設定中檢視儲存空間使用量，並一鍵清理未使用的圖片

快捷鍵

  • Ctrl+Z復原上一個卡片或關係名稱拖曳；輸入欄位內仍使用瀏覽器原生文字復原
  • Ctrl+Y或Ctrl+Shift+Z重做上一個拖曳操作
  • Esc關閉目前彈出視窗
  • ←→圖片檢視器中切換上一張 / 下一張
  • Ctrl+V圖片編輯視窗內貼上剪貼簿圖片
  • Ctrl+Enter在編輯彈出視窗中快速儲存
