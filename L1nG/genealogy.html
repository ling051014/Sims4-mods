使用提示— 快速上手與快捷鍵

畫布操作

  • 拖曳空白處平移整個族譜畫布
  • 滾輪以滑鼠位置為中心縮放
  • 雙擊空白處自動適應螢幕
  • 拖曳卡片自動切換為「自由排列」並儲存新位置

相簿瀏覽器

  • 側邊欄相簿瀏覽器：檢視所有模擬市民的相簿圖片
  • 頂端支援按標題 / 模擬市民名稱 / 備註搜尋，按模擬市民篩選
  • 每張卡片顯示來源模擬市民與標題；點選開啟大圖檢視器
  • 檢視器中←→跨模擬市民瀏覽，Esc關閉
  • 不包含頭像 / 寵物頭像 / 背景圖

模擬市民相簿

  • 編輯模擬市民 →相簿：為模擬市民新增多張圖片
  • 每張圖片可設定：標題 / 關聯階段 / 備註
  • 支援拖曳圖片檔案到相簿網格，或按Ctrl+V貼上截圖

圖片儲存

  • 圖片儲存在瀏覽器IndexedDB中，容量是 localStorage 的10 倍以上
  • 首次開啟會自動把舊資料（base64）遷移到 IndexedDB
  • 匯出 JSON時仍會轉回 base64，與舊版工具完全互通
  • 可在外觀設定中檢視儲存空間使用量，並一鍵清理未使用的圖片

快捷鍵

  • Esc關閉目前彈出視窗
  • ←→圖片檢視器中切換上一張 / 下一張
  • Ctrl+V圖片編輯視窗內貼上剪貼簿圖片
  • Ctrl+Enter在編輯彈出視窗中快速儲存
提示

匯出

可選擇匯出目前完整族譜圖片，或匯出 JSON 備份。

族譜圖片

匯出目前完整族譜畫面，不受目前縮放或平移視角限制。

JSON 備份

保留完整族譜資料與圖片，可再次匯入本工具繼續編輯。

JSON 備份會包含目前族譜資料，並將已儲存在瀏覽器中的圖片一併轉回 base64。
